# code        : conf/code/jacobian_psd.py      raw -> results/diag/jacobian-psd_D2.npz

# WHAT IS MEASURED
#   Jr = d/dx [ tweedie_real(model, x, sigma) ]   (64x64 real Jacobian; score.jac_batch, the exact path
#        ScorePrior._eval uses)
#   J  = wirtinger(Jr)                            (32x32 complex; what ScorePrior hands the receiver, after
#        Hermitian symmetrisation -- score.py ScorePrior._eval: "J = 0.5 * (J + J.conj().T)")
#   For a TRUE posterior-mean denoiser under real Gaussian noise of std sigma:
#        Jr = Cov_real(h|q) / sigma^2   ->  SYMMETRIC and PSD,  and  nu*Herm(J) = Cov(h|q) >= 0.
#   asym(Jr) = ||Jr - Jr^T||_F / ||Jr||_F ; lmin/lmax = extreme eigenvalue of the symmetric/Hermitian part;
#   f<0 = fraction of samples with lmin < 0 ; f>1 = fraction with lmax > 1.
#   clipfrac / shift = RouteAClip._matrix_site (Demo/t2_gmm.py:112-122) replayed verbatim on these samples:
#        SigH = nu*Herm(J);  Lam = SigH^-1 - I/nu;  eta = SigH^-1 hH - q/nu;
#        eigenvalues of Lam floored at LAM_MIN = 1e-6;  shift = ||mu - hH||^2/||hH||^2 with
#        mu = (Lam_clipped + I/nu)^-1 (eta + q/nu).   NOTE clip='eta': eta is NOT recomputed after the floor.
#   lmax > 1 is NOT by itself invalid (Cov(h|q) <= nu I is not required for a non-Gaussian prior) -- it is
#   reported as a scale sanity check, and the GMM reference row shows it is benign.
# ============================================================================================
