# ---------------------------------------------------------------- CAUSE, NOT SYMPTOM
# At iteration 1 the cavity is arm-independent: nu_q@1 and alphaH@1 are BIT-IDENTICAL between each
# swapped pair (checked on h4-jswap_D2_C2_snr+0_n4.npz), so the query point q handed to _matrix_site is

#   0 dB : g|scorew 0.152 -> g|scorew+dJ 5.004      d|scorew 1.568 -> d|scorew+gmmJ 0.093

# The damage is injected at the FIRST site formation, before any decoder feedback.  It is upstream of

# CORRECTION to the published claim (b): the clip FIRES at a comparable rate for both denoisers -- the
# GMM's J has lmax>1 on 51-79% of held-out q, which also drives Lambda negative and trips the floor.
# "Clip firing rate" is therefore NOT the discriminator.  The discriminator is that only the learned J is
# INDEFINITE (frac lmin<0 = 0.70-1.00 vs 0.000), which makes (nu J)^-1 a large-magnitude NEGATIVE
# operator, so eta = (nu J)^-1 hH - q/nu explodes while Lambda is floored to +1e-6 and clip='eta' keeps
# the exploded eta.  That inconsistency, not the floor itself, moves the belief mean.
# CORRECTION to its magnitude: the published shift of 6.96e+03 / 2.88e+03 / 8.70e+02 is measured ALONG
# THE ALREADY-DIVERGED trajectory and is therefore partly a symptom.  Measured on held-out q, the clean
# figure is 2.0-4.4 (still 3-6 orders above the GMM's 2.7e-03 - 2.1e-08).  Direction survives; magnitude
# does not.
#
# ---------------------------------------------------------------- DOES IT PRODUCE THE FULL BLER SHAPE?
# Yes.  Partition the published n=128 trials by whether NMSE ever exceeds 1 during the 16 iterations
# (dscore|scorew):
#   SNR   blowup rate   BLER | blew up   BLER | clean   product   observed BLER@16
#   -3       0.836          0.953           0.333        0.852        0.852
#    0       0.984          0.929           0.000        0.914        0.914
#   +6       0.969          0.798           0.000        0.773        0.773
# The blow-up rate RISES with SNR (the Jacobian gets more indefinite as nu shrinks: frac lmin<0
# 0.70 -> 1.00 above), while the conditional BLER given a blow-up FALLS with SNR (the likelihood
# recovers more of the block).  The product is non-monotone and peaks at 0 dB -- exactly the observed
# shape, including NMSE > 1.  The mechanism accounts for the full pattern.
#
# ---------------------------------------------------------------- WOULD IT HAVE BROKEN THE GMM ARM?
# No, and that is the point: the GMM's J is Cov[h|q]/nu computed in closed form, PSD by construction
# (frac lmin<0 = 0.000 at every nu, worst lmin strictly positive, |J-J^H|/|J| ~ 1e-16).  The defect is
# specific to the learned prior and is exactly what gate GD (full-Wirtinger-matrix relative Frobenius
# error, 0.27-0.32 vs tol 0.20 on D1) already measured and failed.
#
