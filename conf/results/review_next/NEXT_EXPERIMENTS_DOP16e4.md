## 0. 모델 (고정)

- 블록 T = 16 심볼(파일럿 Tp = 4 가 먼저, 데이터 12). 기존 생성기의 경로 표현을 그대로 쓴다: H = Σ_ℓ P_ℓ (D2·D3: 경로 L = 3..8 (슬롯 8), SV8e: 80 광선, 38.901: Sionna CIR 경로 — 슬롯 수는 시나리오별 UMi 23, UMa 24, RMa 15; MIX3 는 블록의 시나리오에 따른다). 38.901 의 ΣP_ℓ − H 오프셋(Sionna float32, 상대 ≤ 1.5e-7)은 t > 0 의 H_t 에 남는다 — 무시할 크기.
- 심볼 t (t = 0 = 첫 파일럿) 의 채널: **H_t = H + Σ_ℓ P_ℓ (exp(j 2π ν cos χ_ℓ · t) − 1)**, χ_ℓ ~ U[0, 2π) 경로마다 독립(Clarke/Jakes 등방 산란), ν = f_D T_s (심볼당 정규화 도플러). H_0 = H (정적 시행과 같다). χ 는 **별도 스트림** `np.random.default_rng([20260928, PID, round(10·SNR)+1000, trial])` 에서 뽑아 시행 스트림(H, 비트, 인터리버, 잡음)을 건드리지 않는다. 수신 신호 Y[:, t] = H_t X[:, t] + W[:, t], W 는 그 블록의 잡음 그대로(W = Y_static − H X).
- ν ∈ {0.005, 0.01}: 블록 끝(t = 15) 시간 상관 J₀ = 0.945, 0.790. 참고 규모: 28 GHz·120 kHz SCS (T_s ≈ 8.9 µs) 에서 ν = 0.005 ≈ 22 km/h, 0.01 ≈ 43 km/h (f_D = v f_c / c).
- 수신기·prior·가중치·적합·파일럿은 정적 실험과 같다(수신기는 여전히 블록당 H 하나를 추정한다). genie 는 H_0 만 안다("블록 상수 genie" 참조) — 도플러 아래 genie 는 **상한이 아니며**, arm 들의 채널 NMSE 도 H_0 기준이다.
- **모델의 지위(공개)**: 경로마다 독립인 χ_ℓ 는 한 단말의 이동(χ_ℓ = 도달각 − 이동 방향, 공통 이동 방향)도, 38.901 자체의 광선별 도플러도 아닌 **확률적 등방 산란 모델**(Clarke)이다; 같은 ν 에서 기하 정합 모델보다 대체로 가혹하다. 기하 정합 변형(단말 속도 벡터, Sionna 이동성)은 이 등록에 넣지 않는다.
