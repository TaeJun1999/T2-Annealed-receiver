# 10/16 보강 캠페인 — 원고 수치 표 (공통 규칙 §5 최종 보고)

작성 2026-10-19 CDT (Opus 5.5). 공통 규칙 `gcap/PROMPT_SERVER_COMMON.md` §5 가 요구하는 "원고에 들어갈 수치 (라벨, 판정점, ΣF, Δ0.1 [90%], 필요한 한정어) 를 표 한 개로" 모은 것이다. 수치는 각 등록 문서 §6 과 compare 출력에서 옮겼고 새로 계산한 것은 표시했다. 원고 문장이 아니다. 무엇을 원고에 넣을지는 사용자가 정한다 (아래 "결정 상태").

공통: test 시행 0..2559 (SNR 당 n = 2560), 외부 반복 16, BLER@16. 판정은 표 B 규칙 (판정점별 exact 양측 부호검정 p < .05, 2/3 규칙, power guard). a:b 의 a = 앵커 (첫 arm) 만 실패, b = 둘째 arm 만 실패. ΣF = 판정점 실패 수의 합 (앵커 / 대상 / genie). R = (ΣF_앵커 − ΣF_대상) / (ΣF_앵커 − ΣF_genie). Δ0.1 = SNR@0.1 격차 (앵커 − 대상, 양수 = 대상이 적은 SNR 로 BLER 0.1 에 닿음), 90 % paired bootstrap (B 2000). 검토: 다섯 BLER 등록 모두 verifier · Fable 기록 감사 (MUST 0) 를 거쳤고, V1LS · E1+ 는 Codex 교차 검토도 거쳤다.
