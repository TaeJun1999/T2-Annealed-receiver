### A.2 셀

| 셀 | Nr×Nt | T | Tp | 데이터 심볼 Ns = Nt(T−Tp) | 정보 비트 K = Ns−6 | 파일럿 비율 Tp/T | 최대 goodput K/T (bit/cu) | Eb/N0 − SNR [유도] (전 에너지 / 데이터만) |
|---|---|---|---|---|---|---|---|---|
| C2 | 8×4 | 16 | 4 | 48 | 42 | 0.25 | 2.625 | +1.829 / +0.580 dB |
| C7 | 8×4 | 16 | 6 | 40 | 34 | 0.375 | 2.125 | +2.747 / +0.706 dB |

- SNR 은 layer 하나가 수신 안테나 하나에서 갖는 평균 SNR 이다. σ² = 10^(−SNR/10) (`SYSTEM_MODEL.md:180-198`).
- Eb/N0 식 `SNR + 10log10(NtT/K)` 은 원문에서 Tp = Nt 에 대해 유도됐다. Tp > Nt 에서도 Xp Xp^H = Tp I 이면 파일럿 에너지가 Tp·Nt 이므로 같은 식이 성립한다 [유도].
- 현재 CELLS 의 SNR 격자는 C7·C8 모두 C2 와 같은 −3..15 (7 점)이다 (`common.py:73-74`).

| −9 dB 의 반복 1 σ_t | **0.9964 (위)** | 0.8136 (안, 3.7% 여유) | 0.7046 (안) |
| −3 dB 의 중앙 σ_t, 반복 1 / 2 / 16 [기록] | 0.4994 / 0.3474 / 0.2683 | 0.4078 / 0.3087 / 0.2638 | 0.3531 / 0.2884 / 0.2602 |
| +15 dB 에서 격자 아래 질의 비율 (반복 2 부터 평평) [기록] | 17.6% | 25.7% | **64.4%** |
| −3..+12 dB 에서 격자 밖 질의 | 0 | 0 | 0 |

- 읽기 [유도·추정]:
  - 파일럿만 쓰는 반복 1 의 추정 잡음은 10log10(Tp/4) = **+1.76 dB (C7) / +3.01 dB (C8)** 만큼 좋아진다.
  - 수렴한 반복 16 의 질의 잡음은 Tp 에 거의 무관하다 (−3 dB 에서 −1.7% / −3.0%).
  - 따라서 Tp 의 효과는 반복 1~2 (부트스트랩) 에 몰린다.
- 격자 아래 질의가 V1 에서 어떻게 처리되는지 [기록]: ScorePrior 는 격자 밖에서 "extrapolate, never clamp" 한다 (`score.py:1142`).
  - C8 +15 dB 에서 V1 질의의 64% 가 학습 σ 범위 아래를 외삽한다 (Gaussian 수신기 궤적 기준. V1 의 반복 ≥ 2 궤적은 약간 다를 수 있다).
  - 판정점과 BLER 0.1 교차점은 낮은 SNR 쪽에 있으므로 이 외삽이 frontier·표 B 에 들어갈 가능성은 낮다 [추정]. 다만 +15 dB 의 C8 V1 값은 이 캐비엇을 달고 보고해야 한다.
- 반례 증거 [기록]: C2 −9 dB (1e4 V1, 격자 위) 에서 V1 의 NMSE 중앙값 @1 은 1.723 이고 R2 는 0.648 이다 (`tables_D2_B1e4lo.txt:92,99`). K2 가 C1 −3 dB 에서 본 격자 위 붕괴와 같은 쪽이다.

**D-A3 · 등록 라벨을 받을 비교.**

- 다중성: 셀 간 1차 비교를 1 개로 할지 2 개 (C7·C8) 로 할지 정한다. 2 개면 Holm 을 병기한다 (K1K2 선례: m=3).

**D-A4 · Pareto 주장의 형식.** 후보는 모두 세 갈래 라벨이다.

| 후보 | 비교량 | 세 갈래 |
|---|---|---|
| P-a | Δ₆ = SNR@0.1(V1, C2) − SNR@0.1(b\*, C7), 비짝 90% CI | CI < 0 → "V1(Tp=4) 가 b\*(Tp=6) 보다 적은 SNR 로 BLER 0.1 에 이른다"; CI > 0 → 반대 유의; CI 가 0 을 걸침 → 판정 못함 |
| P-b | Δ₈ = SNR@0.1(V1, C2) − SNR@0.1(b\*, C8) | P-a 와 같은 형식 |
| P-c | P-a/P-b 를 Eb/N0 로 | Δ 에서 0.918 / 2.083 dB 를 뺀다 |

- C2 쪽 값 (V1 −2.23) 은 이미 알려져 있다. 미지수는 C7/C8 의 b\* 뿐이다. 그래서 예측은 약한 예측이다.
  - 위 이동 추정으로는 P-a 가 경계선이다 (b\* C7 −1.7 ~ −2.6 vs V1 C2 −2.23).
  - P-b 는 b\* 가 앞설 가능성이 크다 [추정].
- "비긴다" (동등) 를 주장하려면 동등성 여유 (예: \|Δ\| ≤ 0.5 dB, 90% CI) 를 미리 적어야 한다. 비유의만으로는 쓸 수 없다.
- **[권고]** P-a 를 1차 (SNR 척도) 로, P-b 를 2차로 등록하고 Holm 을 병기한다. P-c 는 보고로 둔다. V1 의 C2 SNR@0.1 에 대한 셀별 절대 CI 는 아직 계산된 적이 없으므로 같은 스크립트로 새로 계산한다.

### C.1 생성 설정 (`selection.md:71-83`, 비판자 코드 `testbed2_phase0/code/sv_probe.py:sv_draw`)

- H = Σ_{c=1..8} Σ_{r=1..10} α_cr a_r(θ_cr) a_t(φ_cr)^H. 반파장 ULA, a(x)_k = exp(jπ k sin x). 단일 V 편파, 양단 omni. uplink (UE Nt=4 송신, BS Nr=8 수신), 협대역 블록 페이딩, LOS 없음.
- 각도:
  - 군집 평균 AoA ~ U[−60°, 60°] (D2 S2 와 같은 120° 섹터).
  - 군집 평균 AoD ~ U[−180°, 180°) (UE yaw 만 무작위).
  - D2 S2 는 AoD 도 ±π/3 이다 (`d2.py:77`). SV 는 전기각 전 범위를 쓴다.
  - 광선 오프셋은 양쪽 모두 Laplacian 이고 표준편차 7.5° 다.
- 이득: α ~ CN(0, 1/80) iid, 군집 전력 균등, 블록별 Σ|α|² = 1.
- 앙상블 정규화 E‖H‖_F² = NrNt 는 초안에서 "학습 스트림에서 계산" 이다.
  - [유도] 블록 정규화 뒤에도 α 는 위상 대칭이므로 교차항의 기댓값이 0 이다. 따라서 E‖H‖_F² = NrNt, E|H_ab|² = 1 이 **해석적으로 정확하다.**
  - → 학습 스트림에서 잰 상수 (≈ 1 ± 1e-3) 로 테스트 생성기를 스케일하는 것보다 해석적 1 을 쓰고 T3a 식 검사 (n=4e6) 를 하는 편이 스트림 의존이 없다. **등록에서 정한다.**
- 분할: 학습 1.6e5 / 검증 5000 / 테스트 7 × 2560 은 서로 겹치지 않는 스트림에서 나온다. 누수 0.000. 생성 비용은 표본당 0.056 ms (1.83e5 개에 0.17 분 CPU).
- 설정 값은 `configs/` YAML 에 두기로 초안에 적혀 있다. **`/home/HTJ/t2/configs/` 는 현재 없다.**
