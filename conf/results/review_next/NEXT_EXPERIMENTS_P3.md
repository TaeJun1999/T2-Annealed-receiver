## 2. 설계

루프는 규칙과 무관하게 진행하므로(규칙은 **언제 멈출지·어느 실행을 고를지**만 정한다) 32 반복을 돌려 두고 규칙을 오프라인으로 적용한 결과는 온라인과 **동일**하다 — RouteA.run 은 n_iter 에 의존하는 일정이 없고 RNG 를 쓰지 않으며(검토에서 시행 3200~3201 로 비트 동일 확인), 이 등가성은 RouteA/RouteAClip arm 에만 해당한다(R3-BiG-AMP 는 발산 시 재실행하므로 P3 에 넣지 않는다).

### 2.1 P3-A 반복 연장 (rule = 언제 멈추나)

- 규칙 (블록마다, 오프라인):
  - **R16** = 반복 16 의 결과. 32 반복 실행의 반복 1~16 로그는 기준 16 반복 실행과 **비트 동일**해야 한다(수용 검사; 어긋나면 실행 무효).
  - **R32** = 반복 32 의 결과.
  - **R-adapt** = t ∈ [16, 32] 중 처음으로 **r_{t−1} < 1e-3 이고 r_t < 1e-3** 인 t 에서 멈춤(없으면 32). 비용 = 멈춘 t.
- **H6a**: R32 는 R16 보다 실패가 적다 (prior 별 부호검정 2개).
- **H6b**: R-adapt 는 R16 보다 실패가 적다 (prior 별 2개). R-adapt 와 R32 의 순 차이, 평균 반복 수(prior 별 1280 블록 평균)는 **보고**.

### 2.2 P3-B 감쇠 (rule = 루프 상수)

- 변형 arm (`build_our_arms(p3_arms=True)`, `route_a(..., beta=0.5)` / `route_a(..., beta_fb=0.5)`):
  - `V1-b05`, `bstar-b05`: beta = 0.5 (extrinsic 쌍 (rD, tauD) 의 감쇠; v1 값 0.7).
  - `V1-fb05`, `bstar-fb05`: beta_fb = 0.5 (사후 피드백 (xbar, v) 의 감쇠). D-15/Q-24 는 exp_0921 A(D1 계열 Gaussian Kronecker 4×4, 16 반복)에서 beta_fb = **0.7** 이 해로웠다는 측정(0:7, 5:24, 5:21, 3:12, 2:16, p ≤ 0.035; `docs/logs/decision_log.md:171`)으로 "감쇠 없음" 을 닫았다. 여기서는 **D2·다른 값(0.5)에서의 재현**이고 새 arm 의 ablation 이지 그 결정의 변경이 아니다.
- **H7-b05, H7-fb05**: 변형의 R16 이 기본 R16 보다 실패가 적다 (변형 × prior = 4개 부호검정, 각각 따로 판정).

### 2.3 P3-C 관측 기준 재시작 (rule = 어느 실행을 고르나)

- 실행 추가 없음: 블록마다 {기본, b05, fb05} 세 실행의 반복 32 결과 중 하나를 고른다.
- **S-res** = r_32 가 가장 작은 실행 (동률·전부 +∞ 이면 기본). **S-conf** = alphaD_32 가 가장 **작은** 실행 (보고 전용; 동률이면 기본).
- **오라클** = 세 실행 중 하나라도 반복 32 에서 성공이면 성공 (참 비트 사용) — 배치 불가 상한 참조, arm 아님.
- **H8**: S-res 는 **기본 R32, b05 R32, fb05 R32 각각**보다 실패가 적다 (prior 별 3개 = 6개 부호검정). 어느 하나라도 지지가 아니면 그 prior 에서 H8 은 지지가 아니다(단일 실행 하나를 고른 것과 구별할 수 없으므로). 선택 빈도표(실행별 선택 수, 실패·성공 블록 나눠서)는 필수 보고. 비용 = 실행 3개.

### 2.4 prior 이득의 분리 (사전 고정된 검정)

- 규칙 ∈ {R32, R-adapt, S-res} 마다, 시행 i 에서 **d_i = (fail_V1^rule − fail_V1^R16) − (fail_b\*^rule − fail_b\*^R16)**, d = 0 제외, exact 양측 부호검정(불일치 < 6 → UNDECIDED). 3개 검정.
- 판정 문장: p < 0.05 이고 #d>0 > #d<0 (b\* 가 더 많이 회복) → "**이득의 일부는 루프 정체였다**"; p < 0.05 이고 반대 → "**루프와 무관한 prior 이득**"; 그 외 → "**판정 불가**". 규칙별 V1 대 b\* 격차의 부호검정 결과는 함께 보고하되 이 판정을 대신하지 않는다.

## 3. 판정·채택·확증 (여기서 고정)

| 가설 | 검정 (C2 −3 dB, n=1280, 같은 시행, prior 별) | 결과 |
|---|---|---|
| H6a | R32 vs R16 | 지지 / 판정 불가 / UNDECIDED |
| H6b | R-adapt vs R16 | 〃 |
| H7-b05, H7-fb05 | 변형 R16 vs 기본 R16 | 〃 (변형·prior 별 4개) |
| H8 | S-res vs {기본, b05, fb05} 의 R32 각각 | 3개 모두 지지일 때만 그 prior 에서 지지 |
| §2.4 | 상호작용 부호검정 (R32, R-adapt, S-res) | 루프 정체 일부 / prior 이득 / 판정 불가 |

- **채택 규칙(테스트 확증 후보)**: H6b 가 **두 prior 모두** 지지이고 두 prior 모두 net(R-adapt − R32) ≤ +3 이면 **R-adapt**; 아니면 H6a 가 두 prior 모두 지지이면 **R32**; 아니면 **후보 없음**. 감쇠 변형·S-res 는 이 문서에서 확증 후보가 되지 않는다(지지되면 별도 등록).
- **헤드라인 교체 없음.** P3 는 "루프 규칙을 바꾼 별도 표" 다. 16 반복 헤드라인 표는 그대로 둔다.
- **테스트 집합 확증(실행 여부만 사용자 결정, 내용은 여기서 고정)**: 1차 비교 = **채택 규칙 vs R16**, V1 과 b\* 각각, 테스트 집합 0..2559 의 **C2 −3/0/+3 dB** (3점 규칙 + 08_SPEC §2 power guard: 3점 모두 있고 ≥ 2점에서 불일치 ≥ 6; 통과 = ≥ 2점에서 채택 규칙의 실패가 적고 p < 0.05), 나머지 SNR 보고 전용. 실행 = 새 태그 32 반복 1회(`--iters 32`, 같은 arm 구성); R16 참조 = 그 실행의 반복 16 결과이며 **`raw_B16e4k` 와 비트 동일**해야 한다(Demo 해시 동일). 통과·실패 어느 쪽이든 별도 표로 기록하고 헤드라인은 바꾸지 않는다.
- 발산 블록은 그대로 세고 빼지 않는다.
