## 0. 모델 (고정)

- 수신(기지국) 배열 회전 δ: 모든 경로의 도래각 θ → θ + δ (D2·D3: 경로, SV8e: 광선, 38.901: Sionna 기지국 yaw + δ — 수신 배열 응답과 방향 관계가 함께 바뀐다). 송신 측·경로 이득·경로 수·지연·잡음은 그대로; 모든 난수 추출이 같아 시행 스트림은 정적 base raw 와 같다(비트·인터리버·잡음·채널의 무작위 부분 동일, H 만 회전).
- δ ∈ {15°, 30°}: S2 부채꼴 ±60° 가 [−45°, 75°] · [−30°, 90°] 로 이동. ULA 응답은 sin θ 로 들어가므로 회전은 공간 주파수 ψ = π sin θ 의 **평행이동이 아니라 endfire 쪽 압축**이다: ψ 지지집합(0° 학습) 밖으로 나가는 경로 비율 12.5 % / 25 %, 수신 측 앙상블 유효 계수 erank(Rr) Nr=8: 7.35 → 6.98 → 5.89, Nr=16: 14.18 → 13.27 → 10.56 (검토자 계산). 30° 는 S2 에서 접힘(|θ| > 90°) 없이 갈 수 있는 최대이고(45° 면 12.5 % 접힘), SV8e 는 라플라스 꼬리로 30° 에서 2.2 % 접힘. 38.901 은 기지국 yaw 를 돌리므로 상대각 부호가 D2 와 반대(대칭이라 동치)이고 하향틸트 위의 yaw 라 편파 결합이 약간 바뀐다. 앙상블 전력 변화 < 1% (selftest_rot, 38.901 포함). `genie-rot → genie(정적)` 는 회전된 채널 자체의 난이도 눈금이다.
- 파일럿: 정적 실험과 같은 행렬(송신 측 앙상블로 정한 것 — 회전은 수신 측이라 파일럿 규칙과 무관). 수신기·prior·가중치·적합 그대로. genie 는 회전된 참 H 를 안다(정상 참조; DOP 와 달리 genie 는 여전히 상한 역할).

- **주 라벨 두 개의 원고 문장(미리 고정)**: 둘 다 (i) → "수신 배열 회전 15°·30° 모두에서 V1 이 b\* 보다 적게 실패"; 15° 만 (i) → "15° 에서 V1 이 적게 실패; 30° 에서는 <라벨 문자열>"; 30° 만 (i) → 두 라벨 문자열 그대로; 둘 다 (i) 아님 → 주장 없음. "분포 표류에 강건" 같은 일반 문장은 쓰지 않는다.
- 범위·한계: 표류는 **고정 공변량 이동**(태그마다 한 각도; 시간에 따라 변하는 표류가 아니다)이고 한 물리 변수(수신 배열 방향)로만 만들었다 — "기지국이 도는" 대신 "사용자 분포 부채꼴이 δ 만큼 옮겨간" 것과 같다(전방향 소자라 이득 패턴 효과는 없다); 수신 측만 고른 것은 파일럿 규칙(송신 측 앙상블)을 바꾸지 않기 위해서다; prior 는 0° 로 학습·적합됐고 재적응·재적합은 별도 등록의 일이다; 문장은 "이 회전 모델·셀·예산" 한정, 등록 사이 보정 없음.
- "회전은 prior 가 쉽게 따라갈 수 있는 이동 아닌가" 에 대해: 응답이 sin θ 로 들어가 ψ 공간의 이동이 선형 변환 하나로 표현되지 않고(위 압축), 어느 arm 도 δ 를 입력으로 받지 않는다.
