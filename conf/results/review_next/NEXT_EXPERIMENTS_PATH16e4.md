- **DeepMIMO 는 이 등록에 없다(공개)**: 실내 `i1_2p4` 는 단말 격자가 7 m × 1 m · 1 cm 간격 · 2.4 GHz(파장 12.5 cm)라, 같은 자리를 다시 지나지 않으면서 채널이 서로 다른 지점은 약 2,000 개(반 파장 간격)뿐이어서 학습 160,000 을 채울 수 없다. 격자가 큰 다른 시나리오는 오늘 다운로드 한도(HTTP 429)로 받지 못했다. 사용자 지시("일단 Sionna 빠르게")에 따라 Sionna 만 먼저 한다.

## 3. 미리 적는 예측 (빗나가면 그대로 쓴다; 도시 풀 두 개의 결과, ROOM16e4 §0 의 SRB 통계·선별값, 아래 §0 을 본 뒤의 예측이며, SRP 에서도 SRB 에서도 prior 의존 arm 의 BLER 은 본 적이 없다)

1. **표 B: (i)**. 확신 중간 이하(ROOM16e4 예측 1 과 같은 근거; 여기는 방향이 두 가지뿐이라 채널 다양체가 더 작아 GMM 에 더 유리할 수 있다). 채점: (i) = 적중; (ii)·(iii) = 빗나감; (iv) = 채점 불가.
2. **판정점 = −3 / 0 / +3 dB 이고 POWERED**. 확신 낮음(§0 의 선별값이 SRB 수준이면 +3 dB 가 아슬아슬하다). 채점: ROOM16e4 예측 2 와 같다.
3. Perfect CSI 의 BLER 수준·테스트 풀의 랭크 통계: 관측됨(채점 제외; §0).
4. 1차 ΔR 의 포화 가드는 발동하지 않는다. 채점: 미발동 = 적중.
5. 회수율 R(−3 dB) 의 90 % CI 하한 > 0 (가드 발동이면 채점 불가).
6. `R2-ours-G → b*`: b\* 가 ≥ 2/3 점에서 적게 실패.
7. 표 A 에서 V1 과 b\* 의 SNR@0.1 이 둘 다 숫자("> 15" 도 "< −3" 도 아님); 표 B 의 SNR@0.1 격차(b\* − V1) > 0 dB (n/a 면 채점 불가).
8. GB′ median ≤ 0.90.
9. 학습: 평가에 쓰는 시행이 patience 정지이고 그 시행의 epoch ∈ [300, 1500].
10. GMM: b\* = kron 계열이고 K ≥ 1024 (full 계열이면 빗나감).
11. V0: −3 dB 에서 가드 발동률 ≥ 0.5 이고 BLER ≥ 0.9. best 대 last V1: 판정하지 못함(pooled p > 0.05).
12. 대조군 `b* → b*-scalar`: (iii).
13. baseline 15 개(`V1-pilot` 포함): (ii) 0 이고 (i) ≥ 12; `pair_ALDSRP.txt` 의 A3 = (i); `pairB_SPSRP.txt` 의 −3 dB 실패 수 `SBL-pilot` < `R0-pilot@1`. 세 문장 따로.
14. 경계 거리별 분할·누수 층화·NMSE CDF: 예측하지 않는다.
15. 빗나갈 경로: ROOM16e4 예측 16 의 (a)~(f) 그대로(재조정·격자 확장·풀 교체 없음).
