## 2. 라벨 (시드마다; UNDECIDED / 비유의는 "판정하지 못함" 이며 어느 쪽의 증거도 아니다)

| 표 B `b* → V1` (시드 s, C2) | 기록 |
|---|---|
| (i) POWERED 이고 second arm fewer ≥ 2/3 | "시드 s 에서 V1 이 b\* 보다 적게 실패" |
| (ii) POWERED 이고 first arm fewer ≥ 2/3 | "시드 s 에서 b\* 가 V1 보다 적게 실패" |
| (iii) POWERED, 어느 쪽도 ≥ 2/3 아님 | "판정하지 못함 (유의 방향 없음)" |
| (iv) UNDECIDED (판정점 < 3 이거나 불일치 쌍 ≥ 6 인 판정점이 2 개 미만) | "판정하지 못함 (검정력 미달)" — 격자 확장 없음 |
| 학습 실패(UMi28 시드, diverged) | BLER 없음, "학습 실패(시드 s)"; 집계에서는 "판정 못함" 으로 세고 분모 3 은 그대로 |

- 시드 강건성 라벨(§1)은 이 표 B 라벨의 집계다. 셀·예산·prior 한정 문장이며 arm 주장이 아니다. 어느 결과도 헤드라인·UMi28 판정·기존 등록의 §6 을 바꾸지 않는다.
