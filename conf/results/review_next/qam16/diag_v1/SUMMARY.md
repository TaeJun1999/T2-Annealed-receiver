## 진단 (개발 시행; 확신과 한계) — verifier 검토 (결함 4 반영: '같은 질의' 표현, 반복 3 범위, test 범위 문장, 한계 2 개; 확인 필요 2 반영: 안전 SNR 을 추론으로, 격자 출처)

- 네 관찰이 함께 가리키는 것: **고 SNR 의 데이터 보조 반복이 V1 의 score 네트워크를 학습 σ 범위 아래 (≈ 0.5–0.75 s_lo) 에서 질의하고, 그 σ 에서 네트워크 denoiser 의 출력이 크게 틀려 채널 추정이 오염된다.** 배선 (one-shot Tweedie · belief · matrix site) 은 σ 분포가 거의 같은 질의에서 GMM 으로 정상 동작하고, 백색 합성 질의만으로도 같은 σ 에서 네트워크 denoiser 가 망가지므로 (질의의 구조는 필요하지 않다) 원인은 네트워크의 범위 밖 외삽으로 보인다. 변조와 무관 (QPSK 도 같다).
- 학습 σ 격자의 하한은 +15 dB 의 반복 2 질의 σ 와 거의 같다 (위 1.00–1.05). 격자는 M-ours-G (가우시안 prior, score 배선) 의 질의를 QPSK C2 격자 (−3 … +15 dB) 와 모든 반복에 걸쳐 모은 1–99 percentile 이다 (`conf/code/sigma.py` 머리말). **추론 (측정하지 않음)**: 깨지는 σ 경계가 약 0.9–0.95 s_lo 이므로 (합성, 그리고 verifier 가 기존 npz 의 모든 반복 site 를 σ 로 묶어 본 결과 — +15 dB 의 질의는 모든 반복에서 0.938 s_lo 이상) +15 dB 와 +18 dB 사이 어딘가에서 붕괴가 시작될 것이다; +16 · +17 dB 는 재지 않았다.
- 한계: GMM 대조는 V1 의 질의가 아니라 자기 궤적의 질의에서 했다 (q 벡터를 저장하지 않아 V1 의 실제 질의에 GMM 을 다시 적용하지 못함); q · x̄ · v 를 저장하지 않아 Codex 제안 ② (저장한 질의로 denoiser · Jacobian 독립 계산 · 유한차분 대조) 는 하지 않았다 (합성 검사가 그 대신 denoiser 를 직접 시험한다). 두 체크포인트 (UMi28 `_best`, D2 legacy-last) · 8×4 · 개발 시행 40 개 · 세 SNR 만. 붕괴가 시작되는 σ 의 경계 (0.61–0.95 s_lo 사이) 는 좁히지 않았다. test 시행에서의 질의 · denoiser 값은 기록되지 않아 (E5 raw 에 없음) test 붕괴와의 시행 단위 연결은 하지 않았다 — test 와 개발은 같은 SNR 에서 같은 양상 (반복 1 은 정상, 반복 2 부터 붕괴) 을 보인다는 데까지만.
