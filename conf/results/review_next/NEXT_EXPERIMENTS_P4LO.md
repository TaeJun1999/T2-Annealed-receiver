## 0. 질문과 출발점 (판정에 쓰지 않는다)

**질문.** 수신기 루프(EP 검출기 + BCJR, `arms.LOOP` 그대로)를 고정하고 prior 만 "블록의 전파 기하를 아는 참조 prior" 로 바꾸면, 실패 블록 수가 V1 과 얼마나 다르고 R5-genie 와 얼마나 다른가? — V1 → genie 격차를 같은 시행에서 **V1 → LO 격차** 와 **LO → genie 격차** 로 나눠 잰다.

**출발점 (같은 시행의 기존 결과; P3 판정 집합 3200..4479, C2 −3 dB, n=1280, `NEXT_EXPERIMENTS_P3.md` §7.1):** @16 실패 수 V1 173, b\* 307, R5-genie 53 → V1 의 격차 위치 (b\*−V1)/(b\*−genie) = 0.528; @32 V1 154, b\* 290. 보고 전용 점(§7.2, 3200..3839, n=640): C2 +6 dB V1 1 / b\* 6 / genie 1; C5 −3 dB V1 230 / b\* 298 / genie 30 (V1 격차 위치 0.254). 테스트 집합(0..2559) B32e4: C2 −3 dB 회수율 0.453 (1.6e5: 0.470).

**이미 알려진 것 (공개; 이 문서보다 먼저 계산됨):**
- 워크플로 조사 스크래치(`scratchpad/lo_denoise.py`, 세션 임시 파일; 개발 시행 2560..3199 의 `p1_cavity` V1 실제 질의): 반복 16 에서 디노이징 NMSE 중앙값 **LO 0.0215 vs V1 0.0497** (2.3배), V1 실패 블록에서 0.064 vs 0.161. 디노이저 수준의 수치이며 루프 수준이 아니다.
- 스모크(§4, 새 시행 6400..6403, C2 −3 dB): 두 δ 를 **모두** 본 뒤 1차 δ 를 정했다(근거는 선험적 — 참 2차 모멘트에 더 가깝다). NMSE@16: LO-G-d0.001 0.0559/0.0164/0.0229/0.0441, LO-S-d0.001 같은 값(4자리), LO-·-d0.01 0.058/0.0084/0.0234/0.0432, R2-ours-G 0.465/0.218/0.131/0.393. BLER 은 보지 않았다.
- LO-G 와 LO-S 가 같은 것은 해석적으로 성립한다(검토 A7): 가우시안 prior 의 정확 야코비안 J = C(C+νI)⁻¹ 로부터 `RouteAClip._matrix_site` 의 Λ = (νJ)⁻¹ − I/ν = C⁻¹, η = 0 이고, Λ 의 최소 고유값 ≥ 1/λ_max(C) ≥ 1/32 ≫ LAM_MIN = 1e-6 이라 클립이 걸리지 않는다 → LO-S 의 (P, site) 는 LO-G 의 colored 모드와 반올림 차이뿐. 따라서 R3 은 **수치 동일성 점검**이다.

## 2. 판독 규칙 (여기서 고정; 결과 전에 라벨을 정한다. 라벨은 격차의 기술이지 headroom 판정이 아니다)

1차 점 C2 −3 dB, @16, δ = 1e-3, LO-S. 각 규칙은 **세 갈래**이고, "p ≥ 0.05 / UNDECIDED" 는 언제나 "판정하지 못함" 이지 "차이 없음" 이 아니다(v3 §0 house rule).

| 비교 | 갈래 → 라벨 |
|---|---|
| **R1 V1 → LO-S 격차** (같은 배선, prior 만 교체): `V1 → LO-S-d0.001 a:b` | (i) a > b, p < 0.05 → **"LO-S 가 V1 보다 적게 실패 (유의)"** — 크기 = V1 실패 − LO 실패, LO 의 격차 위치를 같이 적는다. (ii) n_d < 6 또는 p ≥ 0.05 → **"V1→LO 격차를 판정하지 못함"** (n_d, MDD 기재). (iii) b > a, p < 0.05 → **"가우시안 참조 prior 가 이 배선에서 V1 보다 많이 실패 (유의)"** |
| **R2 LO-S → R5-genie 격차** (reference 까지): `LO-S-d0.001 → R5-genie a:b` | (i) a > b, p < 0.05 → **"LO-S 와 genie 사이에 유의한 격차 남음"** — 크기 = LO 실패 − genie 실패. (ii) n_d < 6 또는 p ≥ 0.05 → **"LO→genie 격차를 판정하지 못함"** (n_d, MDD). (iii) b > a, p < 0.05 → **"LO-S 가 genie 보다 적게 실패 (기록만)"** |
| R3 수치 동일성 (보고): `LO-G-d0.001 ↔ LO-S-d0.001` | 블록별 실패 벡터 일치 여부와 a:b. §0 의 해석적 동일성과 대조; 다르면 원인(반올림·클립 발동)을 적는다 |
| R4 서술 플래그 (보고, 검정 아님): R1·R2 의 갈래가 @32 에서도, δ = 1e-2 에서도 같으면 "안정", 아니면 "반복 수/δ 에 따라 갈래가 다름" 을 적고 두 값을 모두 싣는다 |
| 보고 전용 점 (C2 +6, C5 −3): 같은 표를 "보고 (라벨 없음)" 머리말로. C5 의 상대 이득 지표(§3.5)는 **격차 위치의 증가 (LO-S 위치 − V1 위치)** 로 고정: C2 는 LO 위치 − 0.528, C5 는 LO 위치 − 0.254 |

**해석 한계(같이 적는다).** R1(i) 만이 "이 루프에서 prior 쪽 개입으로 실패가 줄 수 있다" 의 존재 증거이며 비대칭이다(LO 는 학습 불가능한 정보를 쓴다; 학습 가능한 prior 가 그만큼 얻는다는 뜻이 아니다). R1(ii)·(iii) 는 prior 쪽 개입에 대해 어느 방향의 결론도 주지 않는다(가우시안 대리 + 이 배선 한정; 정확한 D2 조건부 사후평균은 측정되지 않았다). R2 는 어느 갈래든 LO→genie 격차의 크기(또는 판정 불가)를 준다. "V1 은 prior 로 얻을 수 있는 것을 거의 얻는다" 류의 문장은 어떤 갈래로도 쓰지 않는다(LO 는 한 종류의 참조 prior 일 뿐이다).

**결과별 다음 단계 (선택지; 결정은 사용자).** R1(i) → prior 개선(용량·구조·조건화) 실험의 근거 후보(별도 사전 등록·동일예산). R1(ii)/(iii) → prior 개선 실험을 이 결과로 정당화하지 않는다; 오라클의 종류(정확 조건부 사후평균 등)를 바꾼 후속은 별도 등록. R2(i) 의 크기는 수신기·루프 쪽(P3 계열) 후속의 크기 참고치.
