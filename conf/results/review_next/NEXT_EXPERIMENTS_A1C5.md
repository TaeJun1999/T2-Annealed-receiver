## 3. 미리 적는 예측 (빗나가면 그대로 쓴다)

- H9: **지지** (aug 가 적음), 순 #d<0 − #d>0 = +15 ~ +40 (a1 쌍의 개발 신호 −22/640 을 1280 으로 늘리면 ≈ −44, 세 쌍 평균으로 줄어듦).
- 부차: a1 쌍은 p < 0.05 로 aug 가 적음(재현); 3쌍 중 2쌍 이상에서 aug 가 적음; p < 0.05 인 쌍은 1~2.
- 보고 전용: C5 0 dB 는 aug 가 적지만 판정 불가(실패 수가 작아 n_d 부족 가능); C2 −3 dB 는 판정 불가(3단계와 같음).
- GB′: aug ≈ ctrl (차이 0.01 이내). ε_φ: aug < ctrl (augmentation 이 위상 등변성을 높임).
