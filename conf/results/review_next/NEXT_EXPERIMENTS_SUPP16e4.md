## 2. 라벨·문장

| 조건마다 | 기록 |
|---|---|
| k𝔅 = 12, m𝔅 = 0 | "조건 c 에서 V1 이 𝔅 12 개 전부보다 적게 실패" — 원 b\* 라벨을 함께 인용 |
| 원 b\* (i) 이고 위 조건 + R_{X\*} CI 하한 > 0 | "조건 c 에서 등록된 baseline 전부(13 개)와 멀어진다" (이 셀·예산·prior·조건 한정) |
| 그 밖 | "조건 c 에서 𝔅 12 개 중 k𝔅 개에서 (i), (ii) m𝔅 개, 판정 못함 12 − k𝔅 − m𝔅 개" + X 별 라벨·R_X 표 |
| (iv) 인 X | k 에 세지 않는다("멀어졌다" 도 "가깝다" 도 아님) |

- 원고 문장 범위: "비정상 채널 일반" 이 아니라 "이 도플러·회전 모형, 이 데이터셋·셀·예산". §0 의 5 조건에서는 "전부" 문장이 불가능하다는 사실을 문장과 함께 적는다. genie ≥ V1 가드의 두 조건에서는 R_X 대신 절대 격차를 인용한다.
