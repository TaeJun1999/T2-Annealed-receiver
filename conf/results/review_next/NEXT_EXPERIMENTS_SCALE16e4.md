## 2. 라벨·문장 (여기서 고정; "측정" 이지 arm 판정이 아니다. 판정하지 못함은 어느 쪽의 증거도 아니다)

**GMM 프로토콜 한정어 G_d** (아래 (T±)·S_d 문장 끝에 항상 붙임): "(b\* = 등록 프로토콜의 GMM — kron K ≤ 4096, 재시작 3, EM 상한 500 반복·tol/patience 정지 — 이며 최적 GMM 이 아니다; 격자 끝·tol 정지 셀: <§5 목록>)".

### 2.1 1차 (데이터셋 d ∈ {D2, UMi28}, Holm 기준 CI)

| 결과 | 기록 |

- **한정어 (T± 일 때 반드시 붙임; 1차 라벨을 바꾸지 않는다; (T0) 에서는 줄만 보고)**
  - **Q-OP**: L\* 의 CI (그 데이터셋의 Holm 수준)가 1차와 같은 방향으로 0 을 배제하면 "[운영점 정합 강건]". 그렇지 않으면 "[운영점 민감: R\*@0.05 에서 <라벨>]" (<라벨> = L\* CI 에 §2.1 의 (T+)/(T−)/(T0) 규칙을 적용한 것). 어느 셀이든 R\* 가 정의되지 않으면 "[운영점 한정어 정의 불가]".

(2) 그 밖에는 세 실행 — (a) 두 끝 `--extrap K2_C9 K2_C2 --ck c_C9 c_C2`, (b) C9 끝만 `--extrap K2_C9 - --ck c_C9 -`, (c) C2 끝만 `--extrap - K2_C2 --ck - c_C2` (K_max 가 내부인 끝은 원래 '-'; 두 자리 다 '-' 면 외삽 없음과 같은 출력) — 의 R1⁺ − R2⁺ CI (Holm 수준)에 §2.1 규칙을 적용한 L⁺ 가 **셋 모두** 1차 라벨과 같을 때만 "[K 상한 강건]" (b\*⁺ = b\* 인 셀은 "(K/2 가 더 낫지 않음, ΔF_K = …)" 병기); 하나라도 다르면 "[K 상한 민감: 실행 (a)/(b)/(c) 의 b\*⁺ 에서 <L⁺>]" (다른 실행을 모두 나열). (b) 는 (T+) 의, (c) 는 (T−) 의 최악 방향이다. D2 에서는 C2 끝의 c_K = 5.264 로 R⁺_C2 가 크게 내려가(0.509 → 0.346 [90% 0.106, 0.492], §0.1) 실행 (a)·(c) 가 '강건' 쪽으로 기울고, 그래서 실행 (b) 가 (T+) 의 실제 검사다; 미확장 D2 C2 b\* 자체는 반대로 ΔR_D2 에 보수적이다(§1 GMM b\* 행). 이 공개를 §6 에 다시 적는다.
- **데이터셋 문장 S_d**: (T+) **이고** 새 C9 셀의 표 B `b* → V1` 이 (i) 일 때 → "<d> 에서 배열이 8→32 로 커질 때 V1 이 (b\* 대비 상대 격차로) genie 쪽으로 이동하고 b\* 와 멀어진다 (측정, UNGATED, 셀·예산·prior 한정)" + G_d + 한정어. 같은 자리에 절대 격차 ΣF_V1 − ΣF_g (C2 → C9, 90 % CI)를 보고 전용으로 병기한다.
- **공동 문장**: "두 데이터셋 모두 …" 는 S_D2 와 S_UMi28 이 모두 성립할 때만 쓴다(교집합-합집합 검정). "적어도 하나" 문장은 쓰지 않는다. 데이터셋을 합치지 않는다.

### 2.2 2차 단계 (측정, 90 %, 보정 없음; 단계마다 독립)

| 단계 | CI 하한 > 0 | CI 상한 < 0 | 그 밖 |
|---|---|---|---|
| S1 (8→16) | "<d> 8→16 증가" | "<d> 8→16 감소" | "<d> 8→16 판정하지 못함" |
| S2 (16→32) | "<d> 16→32 증가" | "<d> 16→32 감소" | "<d> 16→32 판정하지 못함" |

- 그 단계가 쓰는 셀에 가드가 발동하면 "<d> <단계> 판정하지 못함 (<사유>)".
- **D2 S1 은 채점하지 않는다**(두 끝이 알려진 값): 기록값 R_C6 − R_C2 = +0.314 [90% +0.251, +0.381] 을 "D2 8→16 (기록값, 채점 없음)" 으로 인용한다. D2 에는 S2 만 채점한다.

### 2.3 셀별 (새 3 셀)

- 표 B `b* → V1`: (i)–(iv) 문자열은 38901 §2.1 형식을 따른다 — (i) "<셀·d> 에서 V1 이 b\* 보다 적게 실패 (배열 규모 축 측정, UNGATED)", (ii) "<셀·d> 에서 b\* 가 V1 보다 적게 실패", (iii) "판정하지 못함 (유의 방향 없음)", (iv) "판정하지 못함 (검정력 미달)", 학습 실패는 "학습 실패".
- 𝔅: k𝔅 = 12, m𝔅 = 0 이면 "V1 이 𝔅 12 개 전부보다 적게 실패" 이고, 그 밖에는 개수 문장만 쓴다("𝔅 12 개 중 k𝔅 개에서 (i), (ii) m𝔅 개, 판정 못함 12 − k𝔅 − m𝔅 개").
- **"등록된 baseline 전부(13 개)와 멀어진다"** 는 b\* (i) ∧ k𝔅 = 12 ∧ m𝔅 = 0 ∧ R_X\* 하한 > 0 일 때만 쓴다(이 셀·예산·prior 한정) + G_d.

### 2.4 금지 문구와 다중성

- "모든 baseline" 은 SPARSE-scale 부속 결과 전까지 쓰지 않는다. "등록된 13 개" 로만 쓴다.
- (T0)·(T0-Holm)·(iii)·(iv) 에서 "비긴다"·"동등" 을 쓰지 않는다.
- 빗나간 결과에 "소예산 효과" 같은 해석 문구를 붙이지 않는다. 해석은 사용자가 한다.
- 셀·예산·prior 한정 없는 문장, G_d 없는 (T±)·S_d 문장을 쓰지 않는다. "genie 쪽으로" 는 R 이 상대 통계량임을 붙여 쓴다.
- **다중성 문장**: 등록 1차 검정은 2 개(Holm)다. 한정어 2 × 2 는 새 가설이 아니라 캐비엇 규칙이다. 측정 라벨은 **채점 단계 3 (D2 S2, UMi28 S1, UMi28 S2)** + 표 B 3 + 𝔅 36 이며 개수로만 서술한다. 등록 사이에는 보정하지 않는다(house).
- **MDE (검토 추정)**: SE(R_dp) ≈ 0.023 (D2 C2) · 0.024 (UMi28 C2), C9 도 ≈ 0.03 이면 SE(ΔR) ≈ 0.04, 95 % 반폭 ≈ 0.08. 예측 ΔR ≥ 0.18 이면 검정력은 충분하다. (T0) 가 나오면 "차이 ≤ 0.08 수준" 이 아니라 판정 불가다.
