### 2.2 P2 추세 (셀 c ∈ {C2, C6}, Holm 기준 CI)

| 결과 | 기록 |
|---|---|
| (T+) CI 하한 > 0 | "N′ 를 <N_기준> → <N_새> (<N_새/N_기준> 배) 로 늘릴 때 V1 의 genie 격차 회수율 (b\* 대비 상대 격차) 이 커진다 (<c>, 같은 테스트 시행 짝 비교, b\* 판정점 −3/0/+3 dB, attempt 1 · 학습 집합 1 개 (공개 3·5), <C2: D1 형제 게이트 <기준 PASS / 새 PASS·FAIL> \| C6: UNGATED 예산 축 측정>)" + G_N + 한정어 |
| (T−) CI 상한 < 0 | "N′ 를 <N_기준> → <N_새> (<N_새/N_기준> 배) 로 늘릴 때 V1 의 genie 격차 회수율 (b\* 대비 상대 격차) 이 작아진다 (<c>, …같은 괄호…)" + G_N + 한정어 |
| (T0) CI 가 0 을 포함 | "판정하지 못함 (방향 없음)". 동등성의 증거가 아니다 |
| (T0-Holm) 둘째 셀, 첫째가 (T±) 아님 | "판정하지 못함 (Holm 첫째 미판정)". 둘째의 자체 90 % CI 가 0 을 배제해도 이 라벨이며, 자체 CI 는 보고 전용으로 병기한다 |
| (T-iv) 가드 발동 | "판정하지 못함 (<사유: 정의 불가 / 범위 밖 / 학습 실패 / 적합 실패 / 수용 실패>)" |

- **한정어 ((T±) 일 때 반드시 붙임; 1차 라벨을 바꾸지 않는다; (T0) 에서는 줄만 보고)**
  - **비짝 기준 L⁰** (한정어의 비교 기준; 1차 라벨이 아니다): 실행 (a) 파일의 `R1 - R2 … (--level L)` 줄 (외삽 없음, 비짝, 그 셀의 Holm 수준) 에 (T+)/(T−)/(T0) 규칙을 적용한 라벨. 1차는 짝·한정어는 비짝이라 CI 폭이 다르므로 (§0.3: 비짝 SD 가 짝의 1.4–1.7 배) 한정어는 1차 라벨이 아니라 L⁰ 와 비교한다. **L⁰ ≠ 1차 라벨이면** Q-OP 자리 (와 Q-K 가 강제 조건이 아닐 때 Q-K 자리) 에 '[한정어 판정 불가: 비짝 CI 폭 (L⁰ = <L⁰>)]' 한 줄만 쓰고 강건·민감 어느 쪽도 쓰지 않는다. **Q-K 강제 조건 (아래 Q-K (1)) 은 이 규칙보다 우선한다** (주 세션 결정): 강제 조건이면 L⁰ 와 관계없이 Q-K 자리에는 "[K 상한 민감: 외삽 불가] (<사유>)" 를 쓰고 (강제 사유는 적합·수용·외삽 정의 가능성의 사실이며 CI 폭과 무관하다), L⁰ 규칙은 Q-OP 에만 적용된다. 그래서 강제 조건이고 L⁰ ≠ 1차 라벨이면 두 줄 — Q-K 강제 줄과 Q-OP 자리의 '[한정어 판정 불가 …]' — 이 나온다.
  - **Q-OP**: L\* 의 CI (그 셀의 Holm 수준) 가 L⁰ 와 같은 방향으로 0 을 배제하면 "[운영점 정합 강건]". 그렇지 않으면 "[운영점 민감: R\*@0.05 에서 <라벨>]" (<라벨> = L\* CI 에 위 (T+)/(T−)/(T0) 규칙). 어느 끝이든 R\* 정의 불가면 "[운영점 한정어 정의 불가]".
  - **Q-K**: (1) 강제 조건 (§1 Q-K 행의 다섯 조건; 근거는 그 셀의 Holm 수준 `nscale_qk_<c>_L<L>.txt` 머리말의 `# Q-K: … (forced …)` 줄, 또는 그 수준 (a)(b)(c) 파일 중 어느 `R<j>+` 줄 끝의 '[K 상한 민감: 외삽 불가]') 이면 **L⁰ 와 무관하게** "[K 상한 민감: 외삽 불가] (<사유>)" 를 **강제로** 붙이고 (2) 는 적용하지 않는다. (2) 그 밖에는 실행 (a)(b)(c) 의 R1⁺ − R2⁺ CI (Holm 수준) 에 위 규칙을 적용한 L⁺ 가 **셋 모두** L⁰ 와 같을 때만 "[K 상한 강건]" (b\*⁺ = b\* 인 끝은 "(K/2 가 더 낫지 않음, ΔF_K = …)" 병기); 하나라도 다르면 "[K 상한 민감: 실행 (a)/(b)/(c) 의 b\*⁺ 에서 <L⁺>]" (다른 실행을 모두 나열). (b) 는 (T+) 의, (c) 는 (T−) 의 최악 방향이다. 기준 C2 끝의 c_K = 2.02 는 이미 알려진 값이다 (공개 2).
- **데이터 효율 문장 (E, 2차)**: 90 % 하한 > 0 → "C2 에서 N′ = 1.6e5 로 학습한 V1 (D1 형제 게이트 PASS 레시피, 헤드라인 legacy-last 가중치) 이 <N2/1.6e5> 배의 데이터로 적합한 b\* (N′ = <N2>) 보다 SNR@0.1 이 Δ dB 낮다 (같은 테스트 시행, raw 사이 비짝 90 % CI)" + G_N. 90 % 상한 < 0 → 같은 형식으로 "높다". 그 밖 → "판정하지 못함". 검열 복제 > 5 % → "판정하지 못함 (정의 불가)".
- **합성 문장 S_N (원고용; 조건을 지금 고정)**: C2 — **점 집합 (지금 고정; §5 의 `FALLBACK` 으로만 정해지며 BLER 과 무관)**: `FALLBACK 0` 이면 {1e4, 4e4, 1.6e5, 3.2e5, 6.4e5, 1.28e6} (n = 6, <최대 N′> = 1.28e6, <배수> = 128); `FALLBACK 1` (F1) 이면 {1e4, 4e4, 1.6e5, 3.2e5, 6.4e5} (n = 5, <최대 N′> = 6.4e5, <배수> = 64) 이고 문장 끝에 "(F1: 1.28e6 미실행)" 을 붙인다 — F1 은 BLER 전 §5 에 고정되는 사실이라 집합을 줄이는 것은 결과 뒤 선택이 아니다 (§3 머리말의 F1 채점 규칙과 같은 취급). **F1 이 아닌 결손은 집합에서 빼지 않는다**: `PT B64e4 -` (학습·적합 실패), A 수용 실패로 표 B 가 없는 점, '통과 못함' 은 모두 '통과 아님' 이다. 그 집합의 새 점 각각의 표 B `b* → V1` 출력이 모두 '통과' (POWERED 이고 second arm fewer ≥ 2/3; **D1 게이트와 무관하게 표 B 출력으로만 판정**하고 게이트 상태는 옆에 적는다) 일 때만 "D2 C2 에서 동일예산 표 B `b* → V1` 이 N′ = 1e4 … <최대 N′> (<배수> 배) 의 등록된 모든 예산 점에서 '통과' (C6 의 (i) 에 해당) 이다 (1e4·4e4 는 D1 형제 게이트 FAIL = 예산 축 측정, 1.6e5·3.2e5 는 PASS 레시피, 새 점은 §5 게이트대로; 게이트 FAIL 인 새 점은 표 B 가 통과여도 '예산 축 측정' 으로 표기하고 arm 주장에는 쓰지 않는다 (§2.1 FAIL 행))" + G_N. C6 — `NR16B64e4` 가 (i) 일 때만 "D2 C6 에서 N′ = 1e4 … 6.4e5 (64 배) 의 모든 예산 점에서 (i) (UNGATED 측정)" + 회수율 대역 + G_N. 하나라도 아니면 셀마다 개수 문장만 쓴다 ("위 집합 n 개 예산 점 중 k 개에서 <통과 | (i)>"). **C2**: n = 위 집합 크기 = `FALLBACK 0` 6 / `FALLBACK 1` 5, k = 표 B `b* → V1` 이 '통과' (POWERED 이고 second arm fewer ≥ 2/3) 인 점 수. **C6**: n = 3 ({1e4, 1.6e5, 6.4e5}), k = (i) 인 점 수. **기준점 몫은 기록값으로 지금 고정한다**: C2 1e4·4e4·1.6e5·3.2e5 와 C6 1e4·1.6e5 는 모두 POWERED · second arm fewer 3/3 (`results/tables_D2_{B1e4,B4e4k,B16e4k,B32e4}.txt`·`tables_D2_{NR16run2,NR16B16e4}.txt` 의 표 B 줄) 이므로 k 는 새 점으로만 움직인다 (C2 k ∈ {4, 5, 6} / F1 이면 {4, 5}; C6 k ∈ {2, 3}). '통과 아님' 인 새 점은 사유 (`PT <tag> -` (학습·적합 실패), 수용 실패 (표 B 없음), 통과 못함 (출력 문자열)) 를, C6 의 (i) 아닌 새 점은 사유 ((ii)/(iii)/(iv) 라벨 그대로, `PT NR16B64e4 -`, 수용 실패) 를 괄호로 덧붙인다. **D1 게이트 FAIL 은 '통과 아님' 의 사유가 아니다**: k 와 S_N 성립 여부는 위 조건대로 표 B 출력으로만 정하고, 게이트 FAIL 인 새 점은 표 B 가 '통과' 면 k 에 들되 '예산 축 측정' 표기를 옆에 붙인다 (§2.1 FAIL 행; arm 주장에는 쓰지 않는다).

### 2.4 금지 문구·다중성·공개
