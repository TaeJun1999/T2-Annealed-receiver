## 2. 라벨 (시드마다) — SEEDS16e4 §2 표 그대로
(i) "시드 s 에서 V1 이 b\* 보다 적게 실패" / (ii) "시드 s 에서 b\* 가 V1 보다 적게 실패" / (iii) "판정하지 못함 (유의 방향 없음)" / (iv) "판정하지 못함 (검정력 미달)" — 격자 확장 없음 / 학습 실패 → BLER 없음. 셀·예산·prior 한정; 어느 결과도 a1 판정·기존 등록 §6 을 바꾸지 않는다.
