READING

1.  THE sigma-BAND PREDICTION HOLDS.  results/jac_spectrum.txt measured the damage to peak at
    sigma ~ 0.09-0.26 and to vanish by sigma = 0.71.  The receiver's nu shrinks as SNR rises, so the
    operating point should walk into the bad band and out the other side.  The divergence rate does
    exactly that: 0.332 -> 0.488 -> 0.492 -> 0.523 (peak at +6 dB) -> 0.344 -> 0.242 -> 0.082.
    At -3 dB nu is large and the site is still usable; at +15 dB the pilot-only estimate is already
    accurate enough that a broken prior update cannot drag it far, and the beta = 0.7 damping caps
    the excursion.  This closes the gap the divergence diagnosis recorded as unexplained.

2.  IT IS THE SIGN, AT EVERY SNR.  dscore|abs1e-2 floors the eigenvalue MAGNITUDE at 1e-2 while
    KEEPING the sign: it stays broken everywhere (0.098-0.875, NMSE>1 in 2-40% of trials).  Fixing
    the conditioning does not help; fixing the sign does.

3.  EVERY REPAIR REMOVES THE DIVERGENCE COMPLETELY.  fraction NMSE>1 = 0.000 at all seven SNRs for
    both the PSD projection and the scalar site.  Not reduced -- zero.

4.  THE REPAIRED LEARNED PRIOR BEATS THE FITTED GMM AT EVERY SNR:
      -3 dB  0.168-0.184 vs 0.324   (~1.9x)
       0 dB  0.039-0.043 vs 0.094   (~2.3x)
      +3 dB  0.004-0.016 vs 0.020
      and 0.000-0.008 vs 0.000-0.016 above that, where the cell saturates.
    It also beats the Gaussian arm everywhere.  The three repairs agree with each other to within
    their own Monte-Carlo error, which is what one expects if they are removing the same defect.

WHAT THIS IS NOT
  - Not an arm result.  The checkpoint here FAILED the pre-registered gates; 10_SPEC_stageC §3c
    requires the confirmatory run to use a gate-passing checkpoint at n >= 2560, once.
  - Not equal-budget against the GMM in the strict sense: the learned model saw N=1e4, the same
    budget the GMM fit received, so this particular comparison IS equal-budget -- but the
    confirmatory run will use N'=1.6e5 and therefore needs the matching GMM re-fit (A3), which is
    still running.
  - Not a significance test.  These are marginal rates on paired trials; the pre-registered paired
    sign test with the 3-decision-point rule is what will decide the claim.
